Anijipedia · Worker Builder

เครื่องมือออฟไลน์สำหรับรวม HTML, CSS, JavaScript และ Worker core ให้เป็นไฟล์ worker.js ที่ Cloudflare Dashboard ใช้งานได้ โดยไม่ต้องใช้ Node.js หรือส่งไฟล์ไปยังเซิร์ฟเวอร์ภายนอก

การติดตั้งปกติไม่ต้องใช้เครื่องมือนี้ คุณสามารถใช้ worker.js ที่อยู่ใน ZIP ได้ทันที เครื่องมือนี้มีไว้สำหรับกรณีแก้ไขไฟล์ต้นฉบับในโฟลเดอร์ source แล้วต้องการสร้าง worker.js ใหม่
